# data

## metrics.csv

Одна строка — один день. Пустое поле значит «не измерял» — это нормально,
пропуски лучше нулей, потому что ноль испортит любое среднее.

| Колонка | Что | Единица |
|---|---|---|
| `date` | дата | ГГГГ-ММ-ДД |
| `weight_kg` | вес | кг |
| `bp_systolic` | давление, верхнее | мм рт. ст. |
| `bp_diastolic` | давление, нижнее | мм рт. ст. |
| `pulse` | пульс | уд/мин |
| `temp_c` | температура | °C |
| `sleep_h` | сон | часы, можно дробью (7.5) |
| `sleep_quality` | качество сна | 1–10, 10 — отлично |
| `wellbeing` | самочувствие | 1–10, 10 — отлично |
| `mood` | настроение | 1–10, 10 — отлично |
| `notes` | короткая пометка | текст без запятых |

Шкалы самочувствия, настроения и сна — «больше = лучше».
Шкала боли в записях дня — наоборот, «больше = хуже»; это разные шкалы,
не путать.

Давление разнесено по двум колонкам, а не записано как `120/80`, чтобы
значения оставались числами и по ним можно было строить график.

Взвешиваться и мерить давление лучше в одно и то же время суток —
иначе колебания в данных будут про время измерения, а не про здоровье.

## labs/

Сканы и PDF с результатами анализов. Имя файла — дата и что это:
`2026-07-29-общий-анализ-крови.pdf`. Сами значения, которые важно
отслеживать, стоит переносить в запись дня или в отдельную таблицу —
искать по PDF потом неудобно.

## labs.csv

Показатели из анализов, которые важно видеть в динамике. Одна строка —
одна сдача крови. Главные при болезни Бехтерева — `crp_mg_l` и `esr_westergren`:
по ним видно, держит ли терапия воспаление.

| Колонка | Что | Норма (КДЛ Олимп) |
|---|---|---|
| `crp_mg_l` | С-реактивный белок | 0–5 мг/л |
| `esr_westergren` | СОЭ по Вестергрену | 2–10 мм/ч |
| `esr_panchenkov` | СОЭ по Панченкову | 2–10 мм/ч |
| `hgb_g_l` | гемоглобин | 130–160 г/л |
| `wbc` | лейкоциты | 4–9 ×10⁹/л |
| `plt` | тромбоциты | 173–360 ×10⁹/л |
| `mon_pct` | моноциты | 2–9 % |
| `notes` | лаборатория, обстоятельства | текст без запятых |

СРБ сдавать до любых гормонов и не на фоне простуды — иначе значение
не про болезнь. Сравнивать лучше в одной лаборатории.
