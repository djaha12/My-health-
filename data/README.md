# data

## metrics.csv

Одна строка — один день. Пустое поле значит «не измерял» — это нормально,
пропуски лучше нулей, потому что ноль испортит любое среднее.

| Колонка | Что | Единица |
|---|---|---|
| `date` | дата | ГГГГ-ММ-ДД |
| `weight_kg` | вес | кг |
| `bp_systolic` | давление, верхнее | мм рт. ст. |
| `bp_diastolic` | давление, нижнее | мм рт. ст. |
| `pulse` | пульс | уд/мин |
| `temp_c` | температура | °C |
| `sleep_h` | сон | часы, можно дробью (7.5) |
| `sleep_quality` | качество сна | 1–10, 10 — отлично |
| `wellbeing` | самочувствие | 1–10, 10 — отлично |
| `mood` | настроение | 1–10, 10 — отлично |
| `notes` | короткая пометка | текст без запятых |

Шкалы самочувствия, настроения и сна — «больше = лучше».
Шкала боли в записях дня — наоборот, «больше = хуже»; это разные шкалы,
не путать.

Давление разнесено по двум колонкам, а не записано как `120/80`, чтобы
значения оставались числами и по ним можно было строить график.

Взвешиваться и мерить давление лучше в одно и то же время суток —
иначе колебания в данных будут про время измерения, а не про здоровье.
